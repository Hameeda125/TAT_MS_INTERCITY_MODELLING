TS BASELINE MODEL REPORT
======================================================================

DATASET STRUCTURE
Number of paired trips : 6
Sequence length        : 100
ICE input features     : 17
EV target features     : 13

VALIDATION STRATEGY
Leave-One-Pair-Out (LOPO)
Each complete paired trip is held out as the test set.
No random row-level splitting was performed.
No sliding windows were created.
No information from the held-out pair was used for training.

MODELS EVALUATED
1. Training Mean
2. Route-Bin Mean
3. Point-wise Multi-output Linear Regression

IMPORTANT INTERPRETATION
The six paired trips are the independent experimental units.
The 100 route bins within each trip are ordered observations,
not 100 independent trips.
Performance is therefore evaluated using complete-trip LOPO validation.
The Linear Regression scaler is fitted independently within each training fold.
