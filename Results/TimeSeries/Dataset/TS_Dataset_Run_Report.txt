INTERPRETATION NOTES
--------------------------------------------------------------------------------
The constructed dataset is a distance-based route-progress representation.
It is not raw telemetry-to-telemetry timestamp-aligned sequence data.
Each pair contains exactly the same number of route bins.
Telemetry intervals crossing multiple route bins are allocated using route-distance overlap.
Zero-distance intervals are assigned to the route position where they occur.
Existing Part-1 phase labels are normalized without re-segmenting telemetry.
Charging/refuelling is excluded from the six-phase predictive target.
Final EV TAT is reconstructed after TS prediction using separately calculated EV charging time.
Conservation checks compare the route representation against the original Part-1 telemetry.
100 bins remain a modelling design choice and should be evaluated during scientific validation.
